# zSnap

面向 macOS 的轻量级截图效率工具：区域 / 窗口 / 全屏截图、标注编辑、悬浮贴图、长截图。

- 最低系统：**macOS 14 (Sonoma)**（Apple Silicon / Intel 均可构建）
- 技术栈：Swift + SwiftUI + AppKit + ScreenCaptureKit + CoreGraphics/CoreText
- 形态：菜单栏常驻应用（无 Dock 图标），零第三方依赖
- 定位：个人效率工具，不做账号/云同步/商业化

## 功能总览

| 模块 | 说明 |
|---|---|
| 区域截图 | 全局快捷键（默认 ⌥A，可自定义）或菜单触发；冻结快照选区，遮罩强度可调 |
| 窗口截图 | 选区时悬停自动高亮窗口，点击即截取**窗口自身内容**——被遮挡也能截完整画面、不含阴影 |
| 全屏截图 | 选区时点击桌面空白处 = 该屏全屏；或菜单按显示器选择 |
| 标注编辑 | 箭头 / 矩形 / 椭圆 / 文字 / 马赛克；7 标准色 + 自定义取色；线宽与字号档位；撤销重做；选中移动删除 |
| 输出 | 复制到剪贴板（含全部标注）/ 保存 PNG（默认时间文件名）/ 贴图 |
| 贴图 | 无边框置顶悬浮窗，不抢焦点；拖动、滚轮与四角拖拽缩放、悬停工具栏（关闭/缩放/复制/保存）、多贴图独立 |
| 长截图 | 框选区域后手动滚动页面，帧间锚定拼接自动合成；实时进度 HUD，缺口提示回滚补拍 |
| 设置 | 快捷键自定义、遮罩强度、开机启动（SMAppService） |

## 构建与运行

```bash
./scripts/bundle.sh     # 编译 + 组装 build/zSnap.app（稳定签名 + 图标）
open build/zSnap.app    # 启动（菜单栏出现取景框图标）
swift test              # 运行单元测试（43 项）
```

- 图标重新生成：`swift scripts/make_icon.swift`
- 指定签名身份：`ZSNAP_SIGN_IDENTITY="证书名" ./scripts/bundle.sh`（默认自动使用钥匙串中的 `zSnap Dev` 自签名证书——屏幕录制授权在重建后保留，无需反复授权）
- 首次运行需在「系统设置 → 隐私与安全性 → 屏幕与录制」中授权，应用内提供引导

## 安装

在本机安装为正式应用（两种方式）：

```bash
./scripts/install.sh          # 一键安装：构建 → 退出旧实例 → 装入 /Applications → 启动
./scripts/make_dmg.sh         # 生成 build/zSnap-<版本>.dmg 拖拽安装镜像
```

- 安装到 `/Applications` 后，屏幕录制授权**自动保留**（授权绑定代码签名，与应用路径无关）
- 安装路径变更后，建议在 设置 → 登录时启动 重新开关一次以刷新开机启动项
- DMG 若传给他人：因未做公证，对方首次打开需右键 → 打开（正式分发需 Apple Developer 公证，见 Phase 5 报告）

## 使用说明

### 截图（⌥A 或菜单）

| 操作 | 结果 |
|---|---|
| 拖拽 | 区域截图（支持反方向，实时像素尺寸标签） |
| 悬停窗口后点击 | 窗口截图（基于 ScreenCaptureKit 独立窗口捕获） |
| 点击桌面空白处 | 该显示器全屏截图 |
| Esc / 点击过小 | 取消 |

截图完成后直接进入**统一编辑器**。

### 编辑器

- 工具：选择移动 / 箭头 / 矩形 / 椭圆 / 文字 / 马赛克（真实像素化，区域外不变）
- 颜色：色块按钮 → 弹层选 7 标准色或自定义取色器
- 线宽（2/4/6/8 pt）与字号（小/中/大）：下拉选择，可作用于选中标注
- 文字：点击位置 = 文字块左上角，输入所见即成品所得
- 缩放：滚轮滚动页面，捏合 / ⌘+滚轮缩放；「1:1」= 1 像素对应 1 点（此后缩放窗口图片不动），「适应窗口」恢复自动适配

| 快捷键 | 功能 |
|---|---|
| ⌘Z / ⇧⌘Z | 撤销 / 重做 |
| ⌘C / ⌘S | 复制 / 保存 PNG |
| Delete | 删除选中标注 |
| Esc | 逐级退出（文字输入 → 绘制 → 选中 → 关闭编辑器） |

### 长截图

1. 菜单「长截图」→ 框选要捕获的页面区域
2. **手动滚动页面**（Safari / Chrome / PDF / 文档 / 编辑器等一切可滚动内容），HUD 实时显示已拼接高度
3. 点「完成」→ 长图进入统一编辑器，可标注 / 复制 / 保存

拼接采用**锚定式帧间匹配**（上一帧底部横带在新帧中定位，多横带一致性校验）：静止帧零追加、上滚不追加、平滑纹理误配自动跳过；滚动过快出现缺口时 HUD 提示回滚补拍，可无损恢复。

### 贴图

编辑器点「贴图」→ 生成置顶悬浮窗（点击不抢当前应用焦点）：按住拖动、滚轮或拖四角等比缩放、悬停工具栏操作、双击关闭、支持多张贴图并存。

## 架构概览

```
Sources/ZSnapCore/
├── App/            # AppCoordinator（状态机 idle→selecting→editing）/ AppDelegate
├── Core/
│   ├── Capture/    # SCK 截图服务、选区覆盖层、窗口识别、长截图拼接、HUD
│   ├── Annotation/ # 标注模型 / 引擎（快照式撤销重做）/ 渲染器（预览与导出共用一份代码）
│   ├── Image/      # 四层坐标转换（屏幕逻辑→像素→图片→显示）+ y 轴翻转
│   ├── Clipboard/  # 剪贴板
│   ├── Pin/        # 贴图窗口与管理
│   ├── Permissions/# 屏幕录制权限
│   └── Shortcut/   # Carbon 全局快捷键
├── Features/       # 编辑器 / 菜单栏 / 设置 / 权限引导
└── Shared/         # 工具 / 设置存储（UserDefaults）
Tests/               # 43 项单元测试（坐标转换 / 拼接算法 / 标注引擎 / 导出像素校验）
docs/                # 需求文档 + Phase 0–5 验收报告
scripts/             # bundle.sh（打包）/ make_icon.swift（图标）
```

设计要点：原始截图只读，标注以归一化坐标独立存储；一份渲染代码同时服务画布预览与导出，所见即所得；编辑器不依赖屏幕尺寸（为长截图预留）；状态机拒绝并发截图流程并全程留痕（`/usr/bin/log show --info --predicate 'process == "zSnap"'`）。

## 已知限制

- 长截图基于平移假设：吸顶/悬浮元素会产生重复带；大面积纯色区域可能触发缺口提示（回滚补拍可恢复）；兼容性以实测为准
- 窗口截图含窗口真实形状（圆角处透明）；个别受保护窗口回退为区域裁剪
- 贴图在 macOS 全屏 Space 的置顶表现受系统窗口层级机制约束
- 自签名应用不入 App Store；对外分发需 Apple Developer 证书
